# 城市末端配送模拟 · 到货签收与代收款项交接台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

- **订单登记**：应收款、现金与电子支付、温区上限、返仓点；骑手/站点容量不足（含未关闭返仓单占用）不得登记。
- **超温订单**：实测温度高于温区上限时禁止签收，只能拒收并自动生成返仓单。
- **返仓单**：占用原骑手与站点容量，关闭后才释放。
- **签收 / 复签**：签收留存付款快照 v1；复签必须填写原因，生成新版本快照，历史版本保留。
- **交班对账**：按骑手汇总已签收未结算订单的最新快照，实缴与应收必须对平；有差额时挂账金额须覆盖差额，否则不得签收交班。
- **冲突列表**：汇总款项差额、超温待拒收、返仓未关闭，逐条列出订单、骑手、差额、温度。
- 数据保存在 localStorage，刷新后订单、款项、返仓和版本保持一致。

## 目录结构（数据 / 规则 / 界面分离）

```
src/
  data/       类型、种子数据、localStorage 持久化
  rules/      纯函数业务规则：签收拒收、交班挂账、容量占用、冲突检测
  store/      Pinia 状态层，串联数据与规则
  components/ 界面：订单登记、签收台、交班对账、返仓单、冲突列表
```
